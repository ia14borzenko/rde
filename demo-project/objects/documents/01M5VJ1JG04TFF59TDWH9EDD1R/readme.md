## P0-3: статичный image1 соседствует с живыми вставками (оставлен осознанно)

- `word/media/image1.png` (55 283 байта, 960×510, подпись
  «Рисунок 1 — Статистическая обработка реализаций случайного процесса») —
  ручной ассет эпохи M3: байт-в-байт совпадает с `word/media/image1.png`
  из фикстуры `crates/rde-doc/tests/fixtures/base-report.docx`.
  Ни один скрипт `objects/artifacts/*/script.py` PNG не порождает
  (выходы артефактов — только SVG/JSON/CSV), генератора image1 в репозитории
  нет, воспроизвести её скриптом нельзя.
- Живые рисунки `word/media/rde-figure-v4.png` / `rde-figure-v6.png`
  (640×360) — растеризация движком (`rasterize_svg`) SVG-выходов артефактов
  `01M5VJ1JG0QQJM2S6R76FQCZ25` (`out/plot.svg`) и
  `01M5VJ1JG07RAAH8W7QHC1VX6P` (`out/line.svg`); лежат в `w:sdt`
  с тегом `rde:<id>`, обновляются из данных.
- Сосуществование корректно: статичная подпись «Рисунок 1» — обычная
  нумерационная база (движок при перенумерации считает её, пропуская только
  live `para_id`), живой кросс «Рисунок 2» сходится. Удаление image1
  потребовало бы ручной хирургии бинарного `.doc.rde` без операции движка
  (part + rels + drawing-абзац + блоки `customXml` + `body_hash`) и
  безвозвратно стёрло бы невоспроизводимый контент — риск выше пользы.
  Инвариант соседства пинится тестом
  `static_legacy_figure_coexists_with_live_figure` в `crates/rde-doc/tests/doc.rs`.
