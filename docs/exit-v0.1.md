потери данных; изменение скрипта помечает зависимые артефакты устаревшими, обновление и откат

## Как воспроизвести проверку

```bash
cd /home/admin-pc/proj/rde-dev/rde
export PATH="$HOME/.cargo/bin:$PATH"
cargo test --workspace                         # 136 тестов
cargo run -p xtask -- ci                       # ядро + docx-гейты + схемы

cargo run -p rde-ui --example screenshot -- /tmp/rde.png artifacts "Статистики"
```
